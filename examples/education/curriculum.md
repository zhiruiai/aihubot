# 人教版数学练习索引

| 练习     | 册次与知识点                                            | 学生能够做什么                                     |
| -------- | ------------------------------------------------------- | -------------------------------------------------- |
| 十格种子 | 一年级上册第二单元「6～10的认识和加、减法」             | 用十格里空出的格子解释减法，并用加法核对。         |
| 等式天平 | 七年级上册第五章「一元一次方程」，5.2「解一元一次方程」 | 找出第一个不等价的变形，逐项分配，求解后代回原式。 |
